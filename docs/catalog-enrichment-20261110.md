# Catalog, categories and logos — 2026-11-10

## Published content
6,064 URL entries: existing 5,975 plus 89 researched HTTPS entries.
The 89 previously passed two browser playback checks, advancing playlist checks and visual review.
Existing streams were not all retested; neither channel count nor logo coverage certifies playback.

## Categories
12 genre tabs plus Cambodia and All Channels; All is next to Cambodia.
Genres are independent of country. Source metadata matched by exact stream URL, explicit tvg-id,
or globally unique exact name with a trailing quality marker removed. Ambiguous identities retained.
Metadata corrections use a community directory, not a broadcaster ownership guarantee.

## Logos
- 4,426 entries reference decoded, locally cached logos.
- 1,638 entries use channel initials: missing/ambiguous identity or failed image retrieval.
- 86 of the 89 additions have logos. A7 TV, 7Gold and HGTV New Zealand use initials.
- All matched Cambodian channel entries have cached logos.
- Local content-addressed WebP files, maximum 160x160, lazy loaded.
- No external image-host dependency at runtime; broken image events hide the image and retain initials.
- No invented or unrelated logo is used to claim complete coverage.
- Five new-channel alternatives were checked on broadcaster websites after initial image failures.
